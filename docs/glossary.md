# Glossary

- Catkin: ROS 1 build system used by packages under `src/`.
- Cost map: Grid or map representation assigning traversal costs used by trajectory optimization and training.
- Fear: Planner output or reaction path used when the model detects unsafe navigation conditions.
- Mask2Former: Semantic segmentation model family used for RGB-to-semantic inference paths.
- MMDetection: OpenMMLab detection/segmentation framework referenced for semantic inference.
- Omniverse: NVIDIA simulation platform used here through Isaac Sim / IsaacLab extensions.
- PlannerNet: VIPlanner neural network implementation under `viplanner/plannernet/`.
- ROS Noetic: ROS 1 distribution targeted by the ROS packages.
- TF: ROS transform system used to relate world, robot, camera, and goal frames.
- VIPlanner: Visual semantic imperative local planner implemented in this repository.
